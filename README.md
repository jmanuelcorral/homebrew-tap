# homebrew-tap

Fórmulas de Homebrew de [jmanuelcorral](https://github.com/jmanuelcorral).

```sh
brew install jmanuelcorral/tap/bond
```

| Fórmula | Qué es |
|---|---|
| [bond](https://github.com/jmanuelcorral/bond) | CLI para trabajar con varios agentes de código en Herdr |

Las fórmulas se generan desde cada release con `scripts/packaging.mts` del repo de cada proyecto.
